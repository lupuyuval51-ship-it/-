# OPEN

פלטפורמה אחת לגלות, לשוחח ולהשוות **מודלים בקוד פתוח (open weights)**: Qwen, DeepSeek, Kimi, GLM, MiniMax, gpt-oss, Llama, Mistral, Gemma, Nemotron, MiMo, Hunyuan ועוד. עברית/RTL כברירת מחדל, אנגלית/LTR זמינה בלחיצה.

**אפס תלויות** – Node.js 20.3+ בלבד, בלי `npm install`.

## ללא מגבלות שימוש

OPEN לא מטילה מגבלות משלה: אין rate limit, אין תקרת טוקנים (ריק = המודל/הספק מחליט), אין הגבלת אורך הודעה או מספר הודעות, אין הגבלת סטרימים מקבילים, אין timeout על תשובה, ואפשר להשוות כמה מודלים שרוצים. כל אחד מאלה אפשר להפעיל כאופציה דרך `.env` (`RATE_LIMIT_PER_MIN`, `MAX_STREAMS_PER_IP`, `STREAM_TIMEOUT_SECONDS`), וערך 0 = ללא הגבלה.

שני דברים שלא תלויים בפלטפורמה: **הספקים עצמם** (מכסות, קצבים ומחיר של OpenRouter/Together/וכו׳, והמודלים החינמיים שלהם) ו**העלות**. עם מפתחות בשרת וללא הגבלה, כל שימוש מחויב אליכם. Ollama מקומי הוא היחיד שבאמת ללא מגבלה וללא עלות.

## איך "כל המודלים" נשמר מעודכן

הקטלוג לא כתוב ידנית. בהפעלה (ובכל `CATALOG_REFRESH_MINUTES`, ברירת מחדל 6 שעות) השרת:

1. מושך את רשימת המודלים מ־OpenRouter ומשאיר רק מודלים שיש להם repo ב־Hugging Face (הסימן ל־open weights) ופלט טקסט.
2. מעשיר כל מודל מ־Hugging Face API: **רישיון ומספר פרמטרים אמיתי** (למשל "2.8T").
3. שואל כל ספק מוגדר (`/models`) ומצמיד אליו מסלולי הרצה לפי מזהה Hugging Face. מודלים שקיימים רק אצל ספק (למשל Ollama מקומי) מתווספים כרשומות נפרדות.
4. אם המקורות לא זמינים, נשארים עם `data/models.snapshot.json` (צילום מצב שנוצר ב־`npm run sync`).

כך דגם חדש (למשל Kimi K3 או Qwen 3.8) מופיע בלי שינוי קוד.

## הפעלה

```bash
cd open-models-hub
cp .env.example .env     # מלאו לפחות ספק אחד
npm run dev              # http://localhost:3100
npm test                 # 21 בדיקות: registry, streaming, אבטחה, שגיאות ספקים
npm run sync             # רענון צילום המצב מהרשת
```

אין מפתחות בשרת? זה בסדר: כל משתמש יכול להזין **מפתח אישי** ב"הגדרות" (נשמר בדפדפן בלבד, נשלח רק עם הבקשות שלו, לא נשמר בשרת), או להריץ Ollama מקומי בלי מפתח.

## ספקי הרצה

כולם מדברים OpenAI-compatible, אז מתאם אחד מכסה את כולם:

| ספק | משתנה סביבה | הערה |
|---|---|---|
| OpenRouter | `OPENROUTER_API_KEY` | מפתח אחד מכסה כמעט כל מודל בקטלוג |
| Together / DeepInfra / Groq / Fireworks | `TOGETHER_API_KEY` … | מסלולים נוספים לאותו מודל, לפי מזהה HF |
| Hugging Face | `HF_TOKEN` | Inference Providers router |
| Ollama (מקומי) | `OLLAMA_BASE_URL` | ללא מפתח, מזהה אוטומטית מודלים שהורדתם |
| vLLM / LM Studio / llama.cpp / SGLang | `CUSTOM_BASE_URL`, `CUSTOM_API_KEY` | כל שרת תואם OpenAI |

## מה יש בממשק

- **קטלוג**: חיפוש, משפחות (Qwen/DeepSeek/Kimi מוצמדים ראשונים), סינון לפי חשיבה/כלים/ראייה/חינם/מקומי/"זמין עכשיו", מיון לפי חדש/הקשר/מחיר/גודל, פרמטרים (כולל active ב־MoE), חלון הקשר, מחיר ל־1M טוקנים, רישיון, קישור ל־Hugging Face.
- **צ׳אט**: סטרימינג, בחירת ספק, הנחיית מערכת, טמפרטורה, עצירה, תצוגת "חשיבה" של מודלי reasoning, בלוקי קוד.
- **השוואה**: אותה שאלה למספר חופשי של מודלים במקביל, עם זמן לטוקן ראשון, זמן כולל וטוקנים.

## אבטחה

- מפתחות ספקים נשארים בשרת. הדפדפן לא רואה אותם.
- **לפני פריסה ציבורית הגדירו `HUB_ACCESS_CODE`**. בלעדיו כל מי שמגיע לשרת מבזבז את המפתחות שלכם (השרת מזהיר בעת הפעלה ב־production). בקשות עם מפתח אישי לא דורשות קוד, כי הן לא עולות לכם כסף.
- הקטלוג ציבורי. רק `/api/chat` ו־`/api/refresh` מוגנים.
- CSP קשיח בלי inline scripts, פלט מודלים עובר escape לפני הצגה, הגשת קבצים סטטיים מוגנת מ־path traversal, ותקרת גוף בקשה של 32MB (`BODY_LIMIT_MB`) שמגינה על הזיכרון ואיננה מגבלת שימוש.
- אם תפעילו `RATE_LIMIT_PER_MIN` מאחורי reverse proxy, הגדירו `TRUST_PROXY=true` כדי שהמגבלה תעבוד לפי IP אמיתי.

## מגבלות ידועות

- צ׳אט טקסט בלבד. מודלים עם ראייה/אודיו מסומנים בקטלוג, אבל העלאת תמונות עדיין לא נתמכת.
- "קוד פתוח" כאן פירושו **משקולות פתוחות**. הרישיונות שונים (Apache-2.0 ו־MIT לצד רישיונות מותאמים שמוצגים כ־`other`). בדקו את הרישיון בכרטיס ה־Hugging Face לפני שימוש מסחרי.
- היסטוריית שיחה נשמרת בזיכרון הדפדפן בלבד (אין משתמשים/DB).
- מחירים וזמינות באים מ־OpenRouter. ספקים אחרים מחייבים לפי התעריף שלהם.
- הבדיקות מריצות ספק מדומה. לא נבדק מול ספק אמיתי עם מפתח.
