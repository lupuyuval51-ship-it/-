# רשימת המנות של התפריט היומי ב-LUPU-FIT

300 מנות מוכנות, לפי סוג ארוחה. הערכים (קק״ל, חלבון, פחמימות, שומן) הם **הערכה** למנה רגילה אחת, לא מדידה במעבדה.

מקור הנתונים והתמונות מתועד ב-`docs/dishes-source.md` (מקור התמונות ורישיונן לא תועדו; לבדוק לפני השקה ציבורית).

_הקובץ נוצר אוטומטית מ-`shared/dishes/data.ts` (`npm run docs:dishes`), אין לערוך אותו ידנית._
