# EXIT 8 — יציאה 8

משחק אימה־פסיכולוגית בגוף ראשון בהשראת *The Exit 8*: מסדרון תת־קרקעי יפני שחוזר על עצמו בלי סוף.
אותו מסדרון, שוב ושוב — רק שלפעמים משהו בו לא בסדר.

## החוקים

1. אל תתעלם מאנומליות.
2. מצאת אנומליה? הסתובב וחזור אחורה מיד.
3. לא מצאת אנומליה? אל תחזור אחורה — המשך קדימה.
4. צא דרך יציאה 8.

המספר בריבוע השחור על השלט הצהוב הוא היציאה שבה אתה נמצא. החלטה נכונה מעלה אותו ב־1, טעות אחת מחזירה ל־0. כשמגיעים ל־8 נפתחות מדרגות החוצה.

## הרצה

**קובץ אחד:** `exit8/exit8.html` מכיל את כל המשחק (HTML, CSS ו־JS) — אפשר להעתיק אותו לבד לכל מקום, לשלוח אותו או לפתוח אותו ישירות בדפדפן.

הקוד עצמו מפוצל ל־`js/` לנוחות פיתוח. אחרי שינוי בקוד, בונים מחדש את הקובץ היחיד:

```bash
npm run build:exit8
```

לפיתוח אפשר גם לפתוח את `exit8/index.html` (טוען את `js/` ישירות), או להגיש את התיקייה:

```bash
cd exit8 && python3 -m http.server 8000
# http://localhost:8000
```

נדרש דפדפן עם WebGL2 (Chrome, Edge, Firefox, Safari עדכניים). הגופנים (Rubik, Noto Sans JP) נטענים מ־Google Fonts אם יש רשת; בלי רשת המשחק עובד עם גופני המערכת.

## שליטה

| מחשב | מגע |
|---|---|
| WASD / חיצים — הליכה, חיצים ימינה/שמאלה — סיבוב | אגודל שמאל — ג'ויסטיק (דחיפה עד הסוף = ריצה) |
| עכבר — הסתכלות (Pointer Lock; בתוך iframe — גרירה) | גרירה בצד ימין — הסתכלות |
| Shift — ריצה · Esc / P — השהיה | כפתור השהיה בפינה |

## מה יש בפנים

- **30 אנומליות**: האיש הענק, האיש על התקרה, האיש שרודף אחריך, גל אדום, פוסטר שהעיניים בו עוקבות אחריך, שעון משתולל, דלת פתוחה לחושך, עיניים בפתח האוורור, תקרה נמוכה, מסדרון ארוך מדי ועוד.
- **לולאה בלי תפרים**: כל מעבר מתרחש בתוך מסדרון מקשר שסימטרי סביב עצמו, כך שההחלפה לא נראית (נבדק בטסטים ובהשוואת צילומי מסך פיקסל־לפיקסל).
- **תאורה אפויה עם צללים** מהקירות, מנורות פלורסנט, השתקפויות על אריחים מבריקים, ערפל, גרעיניות וויניטה.
- **סאונד פרוצדורלי** (Web Audio): זמזום פלורסנט, אוורור, צעדים על אריחים, צעדים של האיש עם כיוון במרחב.
- **יומן אנומליות** שנשמר בדפדפן, שיא אישי, הגדרות רגישות/שמע/איכות, ומצב "הפחתת הבהובים" (ברירת מחדל אם המערכת מבקשת פחות תנועה).
- עברית (RTL) כברירת מחדל, אנגלית (LTR) מלאה.

## מבנה הקוד

| קובץ | תפקיד |
|---|---|
| `js/logic.js` | פריסת הלולאה, מעברים, חוקי המשחק, רשימת האנומליות (ללא DOM) |
| `js/world.js` | בניית הגאומטריה, הקישוטים, האנומליות הסטטיות ואפיית התאורה (ללא DOM) |
| `js/textures.js` | כל הטקסטורות מצוירות בקוד על canvas — אין קובצי תמונה |
| `js/renderer.js` | רנדרר WebGL2 קטן עם texture array אחד |
| `js/actors.js` | האיש וכל הווריאציות שלו, הגל, הצללית, מחוגי השעון, האישונים |
| `js/audio.js` | סאונד פרוצדורלי |
| `js/main.js` | לולאת המשחק, קלט, ממשק ושמירה |

## בדיקות

```bash
npm run test:exit8
```

הטסטים מוודאים את חוקי המשחק, את המעברים, שהמרחב והתאורה זהים משני צידי כל "תפר", ושכל אחת מ־30 האנומליות נבנית תקין.

מצב דיבוג: `index.html?debug` חושף `window.EXIT8_DEBUG` (טעינת אנומליה מסוימת, הצבת השחקן, הרצת זמן).

---

**English:** a first-person loop-horror game inspired by *The Exit 8*. Spot anomalies in a repeating Japanese underground passage: turn back if something is wrong, keep going if nothing is, and reach Exit 8. Dependency-free WebGL2 — the whole game is the single file `exit8.html` (rebuild it with `npm run build:exit8`); run `npm run test:exit8` for the tests.
