# Archived: earlier "LEVELUP AI" demo

These files are the flat, dependency-free Node.js demo that previously lived at the repository root
(personalized learning paths, BASIC/PLUS/PRO tiers, manual bit payments). They were archived —
not deleted — when LEVEL UP was rebuilt from scratch as a Next.js application.

The upload contained duplicate copies (`name (N).ext`) and was missing its `src/`, `public/`, `tests/`
and `scripts/` folders, so it cannot be run as-is. Nothing in the new application imports from this folder.
Delete it whenever you no longer need the reference material.
