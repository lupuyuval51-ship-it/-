# אתר משרד עורכי דין עומרי דותן

אתר תדמית פרימיום, סטטי לחלוטין (ללא תלויות npm), בעברית RTL, עם סצנת Hero תלת־ממדית (Three.js), 23 עמודים, 8 מאמרים, 6 עמודי תחומי עיסוק, SEO מלא ותפריט נגישות.

## מבנה

```
omri-dotan-law/
├── build.mjs                 # סקריפט הבנייה (Node 20+, ללא תלויות)
├── src/
│   ├── content.mjs           # ← כל התוכן: פרטי קשר, תחומי עיסוק, מאמרים, שאלות נפוצות
│   ├── layout.mjs            # head / header / footer / אייקונים / טופס
│   ├── pages.mjs             # בוני העמודים
│   └── assets/
│       ├── css/style.css     # עיצוב (ערכות בהיר/כהה/ניגודיות גבוהה)
│       ├── js/main.js        # ניווט, נגישות, אנימציות, סינון מאמרים, טופס
│       ├── js/hero3d.js      # סצנת המאזניים התלת־ממדית
│       └── img/              # לוגו, favicon
├── dist/                     # ← הפלט המוכן להעלאה לשרת (נוצר אוטומטית)
└── preview/omri-dotan-law.html  # כל האתר בקובץ אחד לתצוגה מקדימה
```

## עריכת תוכן ובנייה

1. ערכו את `src/content.mjs` (טקסטים, פרטי קשר, מאמרים חדשים).
2. הריצו:

```bash
node build.mjs
```

3. העלו את תוכן `dist/` לשרת (Netlify, Vercel, cPanel, S3 – כל אחסון סטטי).

## לפני עלייה לאוויר – חובה

| מה | איפה |
|---|---|
| טלפון, וואטסאפ, אימייל, כתובת, שעות | `src/content.mjs` → `site` |
| כתובת הדומיין (`url`) – משפיעה על canonical, sitemap ו-JSON-LD | `src/content.mjs` → `site.url` |
| קישורי לינקדאין / פייסבוק | `site.social` |
| שנת ייסוד המשרד | `site.founded` |
| ביוגרפיה של עו״ד דותן | `team.founder.bio` |
| המלצות לקוחות (כרגע לדוגמה – להחליף בהמלצות אמיתיות באישור הלקוחות) | `testimonials` |
| טופס יצירת קשר – חיבור לשרת | ראו למטה |

### חיבור טופס יצירת הקשר

כברירת מחדל הטופס פותח הודעת אימייל מוכנה (mailto). לשליחה אמיתית לשרת:

- **Formspree / Basin / Getform:** ב-`src/layout.mjs`, בפונקציה `contactForm`, הזינו את כתובת ה-endpoint ב-`data-endpoint="https://formspree.io/f/XXXX"`. הטופס שולח JSON (`name, phone, email, topic, message, page`).
- **שרת משלכם:** כל endpoint שמקבל POST JSON ומחזיר 200.

הטופס כולל ולידציה בצד הלקוח, שדה honeypot נגד בוטים ואישור מדיניות פרטיות.

## מה כלול

- **דף הבית** – Hero תלת־ממדי (מאזני צדק בפליז עם השתקפויות, אבק זהב, פרלקסה לעכבר), תהליך עבודה, תחומי עיסוק עם כרטיסי 3D-tilt, אודות, ערכים, המלצות, מאמרים אחרונים, שאלות נפוצות, טופס.
- **אודות** – ביוגרפיה, נתוני משרד, צוות, ערכים.
- **תחומי עיסוק** – עמוד סקירה + 6 עמודים ייעודיים (שירותים, שאלות נפוצות, מאמרים קשורים, CTA).
- **מאמרים** – רשימה עם חיפוש וסינון לפי קטגוריה, 8 מאמרים מלאים עם זמן קריאה, שיתוף, ניווט בין מאמרים, סכמת Article.
- **צור קשר** – כרטיסי קשר, טופס, שעות פעילות, מפה סכמטית + קישור לגוגל מפות.
- **עמודים משפטיים** – הצהרת נגישות (נדרש בישראל), מדיניות פרטיות, תנאי שימוש, 404.
- **SEO** – title/description לכל עמוד, canonical, Open Graph, JSON-LD (LegalService, Article, BreadcrumbList), sitemap.xml, robots.txt.
- **נגישות** – תפריט נגישות (הגדלת טקסט, ניגודיות, מצב כהה, הדגשת קישורים, עצירת אנימציות), ניווט מקלדת, skip link, ARIA, כיבוד `prefers-reduced-motion` (הסצנה התלת־ממדית מוצגת כפריים סטטי).
- **ביצועים** – ללא פריימוורק, CSS אחד, JS ואנילה, Three.js נטען מ-CDN רק בדף הבית, הרינדור נעצר כשה-Hero מחוץ למסך.
- **ערכות נושא** – בהיר (ברירת מחדל), כהה (לפי העדפת מערכת או ידנית), ניגודיות גבוהה.

## הוספת מאמר

הוסיפו אובייקט למערך `articles` ב-`src/content.mjs`:

```js
{
  slug: 'my-article',            // שם הקובץ באנגלית
  title: 'כותרת המאמר',
  category: 'דיני עבודה',        // אחת מהקטגוריות ב-categories
  date: '2026-10-01',
  excerpt: 'תקציר של משפט-שניים.',
  body: `<p>...</p><h2>...</h2><ul><li>...</li></ul>`,
}
```

והריצו `node build.mjs`. העמוד, הסכמה, ה-sitemap והקישורים הפנימיים נוצרים אוטומטית.
