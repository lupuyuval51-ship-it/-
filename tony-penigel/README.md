# טוני פניג'ל · תכנון ועיצוב פנים — אתר תדמית

אתר תדמית חד־עמודי (One-Page) ברמה פרימיום עבור **טוני פניג'ל — תכנון ועיצוב פנים**, גן השומרון.

## מה יש באתר

- **סצנת תלת־ממד חיה (Three.js)** — חדר מרחף מקווי זהב: קשת, ספה, שולחן קפה, גוף תאורה ואבק זהב מרחף. הסצנה מגיבה לעכבר ולגלילה.
- **חוויית גלילה קולנועית (GSAP + ScrollTrigger + ScrollSmoother)** — גלילה חלקה, חשיפות תוכן, סקשן "התהליך" בגלילה אופקית מוצמדת, וטקסטים שמתבהרים תוך כדי גלילה.
- **RTL מלא ועברית מוקפדת** — טיפוגרפיה: Frank Ruhl Libre (כותרות) + Heebo (טקסט רץ).
- **גלריית הדמיות** — ארבע הדמיות קונספט שנוצרו במיוחד לאתר בהתאמה לשפה העיצובית (זהב, שמנת, אלון, פליז).
- **טופס לידים → וואטסאפ** — ללא צורך בשרת: הטופס מרכיב הודעת וואטסאפ מוכנה למספר 052-772-8175.
- **רספונסיבי מלא** — כולל תפריט מובייל, התאמות ביצועים (פחות חלקיקים במובייל) ותמיכה ב־prefers-reduced-motion.
- **SEO בסיסי** — meta description, Open Graph, ו־JSON-LD מסוג ProfessionalService.

## מבנה הקבצים

```
tony-penigel/
├── index.html          — כל תוכן האתר
├── css/style.css       — כל העיצוב
├── js/main.js          — סצנת התלת־ממד + אנימציות
└── assets/img/         — הדמיות הגלריה
```

## הרצה מקומית

זהו אתר סטטי — אין צורך ב־build:

```bash
cd tony-penigel
python3 -m http.server 8000
# ואז לגלוש אל http://localhost:8000
```

## פרסום

מתאים כמות שהוא ל־GitHub Pages / Netlify / Vercel — מפרסמים את התיקייה `tony-penigel` כ־root.

## סקשן "פרויקטים" — איך מוסיפים את התמונות האמיתיות

באתר מובנה סקשן "עבודות נבחרות" שמוסתר אוטומטית כל עוד אין תמונות. כדי להפעיל אותו:

1. שומרים את תמונות הפרויקטים בשמות:
   `assets/img/projects/project-1.jpg` עד `project-5.jpg`
   (מיפוי מוצע לפי התמונות שנשלחו: 1 סלון עם כורסאות חרדל · 2 מטבח/אירוח · 3 פינת אוכל כפרית · 4 קיר טלוויזיה ונגרות · 5 סלון כהה)
2. זהו. הסקשן, הקישור בתפריט ומספור הסקשנים מתעדכנים אוטומטית.
3. מומלץ תמונות ברוחב 1400px לפחות (תמונות ממוזערות מגוגל ייראו מטושטשות במסכים גדולים).
4. **חשוב:** אחת התמונות שנשלחו נושאת לוגו של סטודיו אחר ("יעל דיילס בכר") — אין להעלות אותה אלא אם מדובר בעבודה של טוני עם זכויות שימוש, ועדיף להשיג את הקובץ המקורי ללא הלוגו.

## דברים שכדאי לאמת מול הלקוחה לפני עלייה לאוויר

1. **שעות פעילות** — באתר מופיע "ימים א׳–ה׳ · 8:00–18:00". לאמת מולה.
2. **טקסטים** — כל הקופי באתר הוא טיוטה לאישורה (סעיף "הגישה", תיאורי השירותים וכו').
3. **תמונות הגלריה** — אלו הדמיות קונספט שנוצרו עבור האתר (וכך הן גם מוצגות בו). כשיהיו צילומים/הדמיות של פרויקטים אמיתיים שלה — פשוט להחליף את הקבצים ב־`assets/img/` ולעדכן כיתובים.
4. **דוא"ל/כתובת** — כרגע מוצג ת״ד 5140 גן השומרון בלבד.
5. **תמונת שיתוף (og:image)** — מומלץ להוסיף `assets/img/og.jpg` ולהפנות אליה מ־meta בעת חיבור דומיין.
