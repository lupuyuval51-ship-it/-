## Verdict

**No GPU is present on this machine.** There is no CUDA device, no
`nvidia-smi`, and `torch.cuda.is_available()` is False. All training in
this environment therefore runs on CPU, which bounds LEKOY RV5 to the
small configuration and to LoRA rather than full fine-tuning.

This is a bound on scale, not a blocker: the pipeline, the configs and
the evaluation suite are all built to run unchanged on a GPU host, and
`configs/rv5_medium.yaml` and `configs/rv5_large.yaml` are written for
exactly that. See *Running the full training elsewhere* at the end.

FP16 executes on CPU but is a trap for training: x86 has no fast fp16
path here and there is no GradScaler on CPU, so it is both slower than
bf16 and more likely to produce NaNs. **BF16 is the precision LEKOY RV5
trains in on this host**, and the configs set it accordingly.

Two caveats the table cannot express:

1. **QLoRA is unavailable at any size**, regardless of memory. It needs
   `bitsandbytes`, whose 4-bit kernels are CUDA-only. The `qlora` column
   above is what it *would* cost on a GPU host with the same budget.
2. **Fitting is not the same as finishing.** A 7B LoRA step fits in RAM
   here and would still take minutes per step on 4 cores. The practical
   ceiling for a run that completes in this environment is the 0.5B
   class — which is why `rv5_small` is the default configuration.

## Running the full training elsewhere

Nothing in the pipeline is CPU-specific. To run RV5 medium or large on a
GPU host, install the CUDA build of torch plus `bitsandbytes`, and pass
the matching config:

```bash
pip install torch --index-url https://download.pytorch.org/whl/cu124
pip install bitsandbytes flash-attn --no-build-isolation
python scripts/train_sft.py --config configs/rv5_medium.yaml
```

| Config | Base model | Regime | Minimum GPU |
| --- | --- | --- | --- |
| `rv5_small` | Qwen2.5-0.5B-Instruct | LoRA BF16 | none — runs on CPU |
| `rv5_medium` | Qwen2.5-3B-Instruct | QLoRA 4-bit | 1× 24 GB (A10, 3090, 4090) |
| `rv5_large` | Qwen2.5-7B-Instruct | QLoRA 4-bit | 1× 48 GB, or 2× 24 GB with DeepSpeed |
