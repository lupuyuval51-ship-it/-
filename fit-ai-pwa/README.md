# FIT AI

מאמן כושר ותזונה חכם — אפליקציית אינטרנט אחת, בלי התקנות ובלי שרת.

## הפעלה
- **הכי מהר:** לחיצה כפולה על `index.html`. הכול עובד, והנתונים נשמרים בדפדפן.
- **כאפליקציה בטלפון (PWA, עובדת גם offline):** העלו את התיקייה לאחסון סטטי עם https (GitHub Pages, Netlify, Vercel) או הריצו מקומית:
  `python3 -m http.server 8080` ואז `http://localhost:8080`. בהגדרות ← "התקנה כאפליקציה".

## Claude (אופציונלי)
