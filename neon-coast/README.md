# Neon Coast — משחק עולם פתוח בדפדפן

משחק פעולה בעולם פתוח בסגנון GTA, כתוב ב־JavaScript ו־Three.js, בלי שום תלות חיצונית מלבד קובץ Three.js המצורף.
ברירת המחדל היא עברית (RTL) עם אנגלית מלאה.

## מה יש במשחק

- **גרפיקה**: צינור פוסט־פרוססינג ב־HDR — הסתרה סביבתית במרחב המסך (SSAO), bloom לניאון ולאורות, קרני שמש, tone mapping (ACES), גרדינג, וינייטה, גרעין עדין, החלקת קצוות (FXAA) וטשטוש מהירות עם הפרדת צבע בנסיעה מהירה; מפות נורמל וחספוס לבניינים, לחזיתות החנויות, לכביש ולמדרכות — כך שחלונות הזכוכית באמת משקפים את השמיים והקירות תופסים אור; מפת סביבה פרוצדורלית להשתקפויות על צבע הרכבים, זכוכית וכביש רטוב בגשם; עננים נעים; צללי מגע לבניינים; חזיתות חנויות עם סוככים בקומת הקרקע; מעקות גג ואורות אזהרה על מגדלים; סימני החלקה על הכביש; שלוליות אור מפנסי רכב בלילה; ריהוט רחוב (ספסלים, פחים, ברזי כיבוי, תחנות אוטובוס, תיבות דואר, עציצים); חיצי נתיבים; שמשיות, מגבות וסירות בחוף.

- **עיר פרוצדורלית** של ~80 בלוקים: כבישים עם 4 נתיבים, מעברי חצייה, רמזורים פועלים, מדרכות, בניינים עם חלונות שנדלקים בלילה, שלטי ניאון בעברית ובאנגלית, שלטי חוצות, פארקים, חניונים, חוף, דקלים, מזח ואוקיינוס עם גלים (שיידר).
- **מחזור יום/לילה ומזג אוויר**: שמש, ירח, כוכבים, ערפל, גשם, פנסי רחוב ופנסי רכב שנדלקים בלילה.
- **נהיגה**: 10 סוגי רכבים (כולל לימוזינה וסופר־קאר) עם גופים מעוגלים, מראות, לוחיות, גריל, סטריפ משטרתי (סדאן, ספורט, מאסל, ג׳יפ, משאית, מונית, ניידת, ימ״מ) עם פיזיקת ארקייד — דריפט עם בלם יד, נזק, עשן, אש ופיצוצים.
- **תנועה חיה**: מכוניות AI שנוסעות בנתיבים, עוצרות ברמזורים, שומרות מרחק, צופרות ועוקפות. הולכי רגל שמסתובבים במדרכות, בורחים מירי ונפגעים מרכבים.
- **מערכת חיפוש (1–5 כוכבים)**: ניידות שרודפות ומחסימות, שוטרים רגליים שיורדים מהרכב ויורים, ימ״מ ומסוק עם זרקור ב־4 כוכבים ומעלה. מתחמקים מהמשטרה על ידי יציאה מטווח הראייה.
- **נשק**: אגרופים, מחבט, אקדח, אקדח תופי, תת־מקלע, רובה ציד, רובה סער, רובה צלפים עם זום וכוונת, ורימונים עם פיזיקה — כיוון מעל הכתף, טעינה, ירי מהרכב. אייקוני הנשק והמפה עוצבו בפיגמה (קובץ "Neon Coast – HUD Icons").
- **8 משימות** עם דיאלוגים, סמנים, טיימרים ופרסים: משימת פתיחה, עבודת מונית (חוזרת), מרוץ רחוב, גניבת רכב תחת חיפוש, חיסול כנופיה בפארק, משלוח חבילות, מרדף לוהט ושוד בנק.
- **מקומות**: 3 חנויות נשק, 2 תחנות משטרה עם שוטרים וניידות בחוץ, 2 בתי חולים, 2 מוסכי צביעה (תיקון + ביטול חיפוש), סוכנות רכב, 2 מסעדות ניאון בורגר (חיים), חנות בגדים עם 7 תלבושות, קזינו עם מכונת מזל, בנק, מתווך חוזים במזח, ודירה (שמירה ושינה).
- **פעילויות צד**: משימות שוטר ברכב משטרה (V), חוזי חיסול חוזרים מהמתווך, מרוצי רחוב ב־3 מסלולים, עבודות מונית.
- **20 אסימוני ניאון** לאיסוף, סטטיסטיקה, שמירה/טעינה ב־localStorage.
- **רדיו**: שלוש תחנות מוזיקה שנוצרות בזמן אמת ב־WebAudio (סינת׳ווייב, היפ־הופ, האוס) וכל אפקטי הקול (מנוע, סירנה, ירי, חריקות).
- **HUD** בסגנון המשחקים הגדולים: מיני־מפה מסתובבת, מפה מלאה, כסף, כוכבים, נשק, שעון, מד מהירות, כתוביות ומסכי WASTED/BUSTED.
- שליטה במקלדת ועכבר, וגם שליטה במגע לנייד.

## הרצה

**הדרך הפשוטה — קובץ אחד:** פותחים את `neon-coast.html` בדפדפן בלחיצה כפולה. זהו. כל המשחק (הקוד, ה־CSS ו־Three.js) נמצא בתוך הקובץ הזה, בלי שרת ובלי אינטרנט. הקובץ שוקל בערך 1MB ואפשר להעביר אותו, לשמור אותו או לשלוח אותו כמו שהוא.

**להרצה מהמקורות (לפיתוח):**

```bash
node serve.mjs 8080      # ואז http://localhost:8080
```

המקורות הם ES modules ולכן דורשים שרת. אחרי שינוי בקוד בונים מחדש את הקובץ היחיד:

```bash
node build-single.mjs    # יוצר neon-coast.html ו־dist/artifact.html
```

הבנייה היא באנדלר קטן וללא תלויות: היא ממזגת את שני קבצי Three.js ואת 25 מודולי המשחק לפי סדר טופולוגי, עוטפת כל מודול ב־IIFE משלו (כדי שלא יתנגשו שמות), ומחליפה כל `import` בפירוק אובייקט מהמודול שכבר נבנה.

## שליטה

| מקש | פעולה |
|---|---|
| W A S D | תנועה / נהיגה |
| עכבר | מצלמה, לחצן ימני – כיוון, שמאלי – ירי |
| Shift | ריצה |
| רווח | קפיצה / בלם יד |
| E | כניסה ויציאה מרכב, אינטראקציה, התחלת משימה |
| 1–5 / גלגלת | החלפת נשק |

| H | צופר |
| M | מפה |
| Esc | תפריט |

## מבנה הקוד

| קובץ | תפקיד |
|---|---|
| `neon-coast.html` | המשחק כולו בקובץ אחד (תוצר בנייה) |
| `build-single.mjs` | הבאנדלר שיוצר את הקובץ היחיד |
| `src/world.js` | יצירת העיר, גרף כבישים ונתיבים, רמזורים, חוף, אוקיינוס, תמונת המפה, רשת התנגשויות |
| `src/vehicle.js` | מודלים של רכבים (פרופיל צד מוקצה) ופיזיקה ארקייד |
| `src/traffic.js` | נהגי AI, מעקב נתיבים, עצירה ברמזורים, מכשולים, יצירת תנועה |
| `src/peds.js` | הולכי רגל, שוטרים וחברי כנופיה |
| `src/police.js` | רמת חיפוש, ניידות מרדף, שוטרים רגליים, מסוק |
| `src/player.js` | שחקן רגלי, נהיגה, ירי, מצלמה |
| `src/combat.js` | ירי hitscan, פריטים לאיסוף |
| `src/missions.js` | מערכת משימות async ותסריטי המשימות |
| `src/hud.js`, `src/ui.js` | HUD, מיני־מפה, תפריטים, חנויות |
| `src/sky.js` | שמיים, שמש/ירח, ערפל, גשם |
| `src/audio.js` | סינתזת קול ורדיו |
| `src/i18n.js` | תרגומים עברית/אנגלית |

---

**English:** Neon Coast is a browser open-world action game (GTA-style) built with Three.js: a procedural neon city with living traffic, pedestrians, a five-star wanted system (cruisers, foot cops, SWAT, helicopter), weapons, eight scripted missions, shops, collectibles, day/night, weather, procedural radio and a full HUD with a rotating minimap. Run `node serve.mjs` inside `neon-coast/` and open `http://localhost:8080`. Hebrew is the default; switch to English on the title screen.
